# Spotify's logos

These are Spotify's official logo files (the full logo and the icon, in black and white), used to credit
Spotify as the source of the song details and to link to songs on Spotify, as Spotify's design guidelines
require: https://developer.spotify.com/documentation/design

They are Spotify's trademarks and are **not** covered by this project's licenses (AGPL 3.0 for the code,
CC BY 4.0 for the shared library and presets). Use them only as Spotify's guidelines allow.
